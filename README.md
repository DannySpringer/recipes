# Recipes

A small static recipe site, hosted with GitHub Pages and built for reading on a phone while cooking.

- `index.html` lists every recipe.
- `recipes/<slug>.html` is one self-contained page per recipe, with an ingredient checklist, numbered steps, progress bar and timers.

To publish: in the repository's **Settings > Pages**, set the source to **Deploy from a branch**, branch `main`, folder `/ (root)`.

See [CLAUDE.md](CLAUDE.md) for how pages are structured and how new recipes are added.
